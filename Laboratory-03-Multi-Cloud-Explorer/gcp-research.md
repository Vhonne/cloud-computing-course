# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform provided by Google. It offers cloud services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, and application development. Organizations can use Google Cloud to build, deploy, and scale applications and services.

## 2. Global Infrastructure

Google Cloud operates through a global infrastructure consisting of regions and zones. A region is a geographic area where Google Cloud resources are hosted, while zones are isolated locations within a region. This structure helps organizations deploy applications with improved availability and reliability.

Google Cloud's global infrastructure allows organizations to choose locations based on factors such as application performance, availability, and data requirements.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor applications, manage projects, and access different Google Cloud services through the console.

## 4. Four Core Services

### Compute Engine

Google Compute Engine provides scalable virtual machines that can be used to run applications and workloads in the cloud.

### Cloud Storage

Google Cloud Storage is an object storage service used to store and retrieve data such as files, images, videos, backups, and other unstructured data.

### Cloud SQL

Cloud SQL is a fully managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed Kubernetes service that helps organizations deploy, manage, and scale containerized applications.

## 5. Three Advantages

1. **Strong AI and Machine Learning Capabilities** – Google Cloud provides a wide range of tools and services for artificial intelligence and machine learning workloads.
2. **Kubernetes Expertise** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service that supports containerized application deployment and management.
3. **Global Infrastructure** – Google Cloud provides a global infrastructure that allows organizations to deploy applications in different geographic locations and improve availability and performance.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:

- Hosting websites and business applications
- Running virtual machines and cloud workloads
- Storing and managing large amounts of data
- Hosting relational databases
- Developing Artificial Intelligence and Machine Learning applications
- Deploying containerized applications using Kubernetes
- Performing data analytics and processing
- Building scalable global applications
- Supporting application development and testing
