# AWS Research

## Amazon Web Services (AWS)

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services including computing power, storage, databases, networking, security, and analytics.

### Key Services

* **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers in the cloud.
* **Amazon S3 (Simple Storage Service)** – Provides scalable cloud storage.
* **Amazon RDS (Relational Database Service)** – Managed database service.
* **AWS Lambda** – Serverless computing service that runs code without managing servers.
* **Amazon VPC (Virtual Private Cloud)** – Enables users to create isolated cloud networks.

### Advantages

* Highly scalable and flexible.
* Large global infrastructure.
* Strong security features.
* Wide variety of services.
