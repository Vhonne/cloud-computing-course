# Reflection Paper – Cloud Concepts

## Cloud Services I Use
In my daily life, I often rely on four cloud services: **Google Classroom**, **Google Drive**, **TikTok**, and **GCash**. 
Google Classroom is essential for my online classes, where I can access assignments, submit outputs, and communicate with my instructors.
Google Drive helps me store and send activities efficiently, ensuring that my files are safe and accessible anywhere. TikTok is not only for 
entertainment but also for my affiliate business, where I promote products and engage with audiences. Lastly, GCash is a vital tool for online 
transactions, allowing me to pay bills, transfer money, and shop conveniently.

## Identify the Models
- **Google Classroom** → *SaaS, Public Cloud*. It is a ready-to-use platform hosted by Google, accessible to anyone with an account.  
- **Google Drive** → *SaaS, Public Cloud*. A file storage and sharing service that requires no infrastructure management.  
- **TikTok** → *SaaS, Public Cloud*. A video-sharing platform hosted by ByteDance, available globally for users and businesses.  
- **GCash** → *SaaS, Public Cloud*. A financial application that enables online payments and transactions, accessible through mobile devices.  

All of these services are classified as SaaS because they are software applications I can use directly without managing servers. 
They are also Public Cloud since they are hosted by providers and open to general users.

## Git & GitHub for Cloud Projects
Version control is crucial in cloud projects because it ensures that every change is tracked and recoverable.
If mistakes occur, I can easily revert to a previous version. In collaborative work, such as capstone projects, GitHub 
allows teams to merge contributions, track edits, and avoid duplication of files. This transparency prevents confusion
and errors while maintaining accountability.  

GitHub also supports organized workflows by showing the complete history of a project. 
This makes conflict resolution easier and ensures that cloud infrastructure management remains efficient. 
In short, version control and GitHub are indispensable tools for teamwork, accuracy, and reliability in cloud-based projects.
